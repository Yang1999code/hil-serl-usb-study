来源：[HIL-SERL：精密接触型插接任务](https://j17tak1mfe1.feishu.cn/wiki/UTBhwgi5KigPiXkgkX0cV4X4n5g)

## 它把官方系统落到哪

松灵机械臂上的 USB 插拔。课程把它当作精密接触型插接的真机案例。

系统组成和官方 USB 例子一一对应：

| 飞书说法 | 对应官方概念 |
| --- | --- |
| Actor 在机器人端，Learner 在 4090 | `run_actor.sh` / `run_learner.sh` |
| 手柄 / SpaceMouse / 键盘介入 | `SpacemouseIntervention` |
| 两腕部 + 第三视角 RealSense | USB 例子的 wrist_1/2 + side camera |
| 末端相对平移，姿态锁定 | 相对末端控制 + 任务约束 |
| 第三视角奖励分类器 | `classifier_keys = ["side_classifier"]` |
| SDK -> ROS2 -> Flask | 官方是 `franka_ros` + Flask |
| 关节限位、EE 限位、ROI 裁剪、WandB | 官方有 pose limit、IMAGE_CROP、wandb |

## 它强调的安全

训练时机械臂会有较大随机运动，需要专用工作空间。这和官方阻抗控制、pose limit、人在环纠正是同一类约束。具体限位数字飞书后半没读到，这里不编。

## 它让你掌握的算法名词

重点：PPO、SAC、RLPD。项目里真正用来更新策略的是 RLPD。SAC 提供 off-policy 最大熵更新；RLPD 再把演示数据混进 batch。

典型任务列表：抓放、轴孔装配 / USB 插拔、线缆布线、PCB 插装。官方仓库已经覆盖其中 RAM/USB/线缆/交接等。
